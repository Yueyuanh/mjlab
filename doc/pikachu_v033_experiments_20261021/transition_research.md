# V033 四足 ↔ 双足转换：方案与小规模实验

日期：2026-10-21。结论：优先采用“四足速度策略 + Down 转换策略 + Up 转换策略 + 双足速度策略”的状态机。训练转换策略之前，需要重新生成 V033 接触感知参考动作。现有旧版模型和参考不能直接复用；本次试验尚未得到可部署的转换控制器。

## 已有能力与关键差异

- 仓库已有 `src/mjlab/tasks/tracking/config/pikachu_transition/` 的 Up/Down 任务，基于 BeyondMimic tracking 框架；其配置导入的是旧 `pikachu_constants`，两份 `Pikachu-Transition-{Down,Up}.npz` 都是 14 关节数据。
- V033 是 22 个非 free 关节、18 个动作，膝部包括受驱动的 knee_up 和被动 knee/knee_mid。参考必须保留四杆闭合，不能将 14 关节动作补零后直接训练。
- V033 四足接地点是 elbow_link STL 上的 hand site；旧任务追踪 arm_yaw_link，末端语义不一致。转换需追踪 base、双侧 ankle 和 elbow，并校验实际碰撞体，不只校验 site。
- 双足/四足的动作维度相同，但默认姿态 offset、动作 scale、观测及归一化器不同。应先分别算物理目标 `q_target = offset + scale * action`，再在物理目标空间平滑交接；直接混合两个原始 action 不正确。
- 四足 arm_roll 参考为右 -90°/左 +90°，双足参考为右 +53°/左 -53°，arm_yaw 也从 +90° 变化至 0°。因此现有“固定姿态 ±5°”奖励在过渡中必须按模式释放或改为追踪时变参考，不能原样累计。
- 四足 elbow 小窗口可尽量保留，但要先验证参考动力学可行性。手脚末端靠近奖励也只在四足稳定阶段启用，起立时允许手离地。

## 本次小规模实验

脚本：`scripts/probe_v033_transition.py`。结果位于 `logs/rsl_rl/pikachu_v033/crawl_e2/compact_20261021/research/transition_probe/results.json`。使用 CPU、单线程，未与训练抢占 GPU。

比较两种候选：

1. 直接在 V033 双足/四足姿态之间平滑插值关节和参考 root pitch。
2. 在 61 个相位点做对称 IK，加入四杆闭合、脚端高度与位置、手端路径、简单 COM 支撑条件及平滑约束。

每种候选分别做 4 秒/8 秒、站起/趴下、两个小初速度扰动，共 8 次；合计 16 次。仿真初始化之后，机身完全自由，不修改 root 状态，只给有力矩上限的原生位置执行器目标。每段之后再保持 2 秒。

| 参考轨迹指标 | 直接插值 | 支撑/闭合 IK |
| --- | ---: | ---: |
| 最大四杆闭合误差 | 1.001 mm | 0.014 mm |
| 最大脚端高度绝对偏差 | 9.08 mm | 3.08 mm |
| 自由机身 PD 严格成功数 | 0/8 | 0/8 |

成功判据为末端 pitch 偏差 <0.20 rad、全过程 root 高度 >0.10 m、无躯干接触、结束平移速度 <0.10 m/s。该判据还没有覆盖策略交接及关节/接触力安全，因此通过也不能视作可部署。

直接插值的趴下试验能最终回到约 1.32 rad pitch 的四足姿态，但中途 root 高度降至约 0.095–0.098 m，未通过全过程高度条件；站起则停在约 1.44 rad，未能起立。IK 改善了运动学闭合，但没有保证动力学平衡，出现了倾倒/躯干接触。不能根据“轨迹看起来连贯”判断转换已实现。

这些结果说明：需要把支撑力转移、COM/动量和末端接触时序纳入轨迹及学习目标。此次 NPZ 只保存候选 qpos/相位，**不是可直接喂入 MotionLoader 的 tracking 数据集**。

## 推荐实现

### 统一机器人与接触

建立独立 `pikachu_v033_transition` 配置，复用 V033 四杆、18 个执行器和手脚 site。为四个模式选定一致的物理碰撞集合，包含脚底胶囊、手端 STL、躯干及需要的自碰撞对；不要在切策略时改变碰撞掩码、质量或关节限位。现有四足/双足的碰撞设置并不完全相同，需要先在统一模型下复测它们的站立与行走。

### 接触阶段

Down：双足减速并稳定双支撑 → 屈膝/移动重心，预先把手伸向地面 → 逐步建立四点支撑并转移载荷 → 达到新的四足站姿并稳定保持 → 交给四足速度策略。

Up：四足停稳 → 后移重心到双脚支撑区域，并通过腿部伸展抬升机身 → 手部载荷逐步降至零 → 抬手/收臂，恢复双足姿态 → 稳定双支撑后交给双足策略。

Up/Down 应独立训练。Up 不是简单倒放 Down：接触建立/释放、动量需求和力矩裕量不同。参考端点应取优化后速度策略的实测静站分布，而非只用标称 keyframe。

### 参考动作与 RL

先用接触感知 IK 或轨迹优化生成低速参考，约束四杆闭合、实际碰撞几何离地、关节限位、速度和执行器力矩。输出按 V033 名序生成的关节位置/速度、body 位置/四元数/速度、50 Hz 时间轴、支撑阶段；在 MuJoCo 自由机身中验证，禁止使用 root 强制跟踪作为成功证据。

复用 tracking 环境的位姿/速度/末端跟踪项，加上手脚接触阶段、站起高度进度、躯干接触、滑移和动作平滑项。训练期采用参考状态初始化与困难片段采样，末尾加入 1–2 秒稳定保持；评估固定从真实起始姿态出发，不能随机从中段重置后算整段成功。

小批量训练建议：每个方向 64–128 环境 × 200–500 轮先做训练通路试验；参考通过运动学和自由仿真检查之后再扩大。该步尚未执行，本次只进行了上述 16 次 PD 物理试验。

### 状态机和交接

推荐 `BIPED → PREPARE_DOWN → DOWN → QUAD → PREPARE_UP → UP → BIPED`，带超时退出/保持状态。

转换入口：速度命令归零，平移速度 <0.03 m/s、角速度 <0.15 rad/s，所需支撑稳定约 0.3–0.5 s。出口按目标姿态、实际支撑和稳定速度共同判断，连续保持约 0.5 s 后，在物理关节目标空间用 0.3–0.5 s 平滑交接。这些是初始设计值，须由 V033 实测调整。

保留各策略自己的观测、默认姿态与归一化统计，交接时正确更新 last_action。转换中采用连续的参考水平 heading，避免从四足的 torso +Z 投影定义突然切换到双足 +X 定义。

尤其要修改/派生 `MotionCommand` 的片尾逻辑：当前 `_update_command()` 越过片尾会调用 `_resample_command()`，后者写入机器人状态。训练中的重采样可用，连续转换评估与部署应在片尾保持并交接，不能靠瞬移完成转换，也不能把 reset 算成功。

### 验收建议

分开报告成功率、摔倒/躯干接触、手脚滑移、四杆误差、关节与力矩峰值、交接目标跳变。先做两个方向各 20 个固定首帧完整试验，再增加初速度/摩擦/起始姿态扰动。完整循环必须连续执行 `四足站 → Up → 双足站/走 → Down → 四足站/走`，中途不重置、不改物理模型；稳定策略的参数不要在调转换时覆盖。

## 研究依据

以下项目页在本次调研中实际读取；抓取文本保存在实验目录的 `research_sources.json`。

- [DeepMimic (2018)](https://xbpeng.github.io/projects/DeepMimic/index.html)：从示例动作学习物理技能，为参考驱动的独立转换策略提供方法依据。
- [BeyondMimic](https://beyondmimic.github.io/)：运动跟踪与技能组合；本仓库的 tracking 基础环境注明采用该框架的实现思路。其效果不能直接视为 V033 已验证能力。
- [AMP (2021)](https://xbpeng.github.io/projects/AMP/index.html)：用动作先验学习风格化控制，适合后续多技能统一，但在当前 V033 可行转换数据不足时，优先级低于显式参考跟踪。

本阶段推荐先完成可验证的独立 Up/Down，再考虑模式条件化单策略或蒸馏；当前直接联合训练会同时引入姿态、接触、观测及奖励冲突，难以定位失败原因。
