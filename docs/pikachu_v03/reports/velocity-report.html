8. 数据文件与复现

每个档位一个 CSV，列契约与 scripts/plot_logs/metrics_csv_dashboard.html 一致：

sample, sim_step, time_s, env_idx, network, <指标列…>
  • time_s 必须存在且单调递增（dashboard 会校验）；
  • 指标列按前缀被 dashboard 归类，本报告录了其中 8 族：joint_position_rad/、joint_target_rad/、joint_velocity_rad_s/、joint_torque_nm/、joint_torque_ratio/、joint_velocity_ratio/、joint_accel_rad_s2/、joint_power_w/；
  • dashboard 还认第 9 族 joint_inertia_torque_nm/，本报告故意没录：它要每个控制步为每个 env 算一次完整质量矩阵（mj_fullM），2048 env × 25000 迭代下开销实打实，而它承载的信息基本能从扭矩与加速度两条曲线推出来。这是已知的缺口，不是遗漏。
  • vel/ 开头的列是本报告专用的速度追踪主线（vel/cmd_* 命令、vel/act_* 实测、vel/err_* 带符号误差、vel/pos_*_w 世界坐标、vel/yaw_w 世界偏航、vel/standing 门控快照）。dashboard 不认这个前缀，会原样忽略，所以两种用途互不干扰。

    --checkpoint logs/rsl_rl/pikachu_v03_velocity/2026-10-09_00-34-34_v03-flat-r06/model_34998.pt \
    --out docs/pikachu_v03/metrics --tag r06-test --seconds 8

uv run python scripts/v03_velocity_report.py \
