# Plot Logs

这里存放 Pikachu 训练、部署与 Metrics CSV 的浏览器分析工具。

## Metrics CSV Dashboard

`metrics_csv_dashboard.html` 用于查看 Viser Metrics 面板录制的 CSV。页面在浏览器
本地解析数据，不会上传 CSV。

推荐从仓库根目录启动带 CSV 发现接口的只读服务：

```bash
uv run python scripts/plot_logs/serve.py
```

然后打开：

```text
http://localhost:8000/scripts/plot_logs/metrics_csv_dashboard.html
```

端口以启动时打印的 URL 为准：默认 8000，若该端口已被占用（常见于上一次
`serve.py` 还在后台跑），服务会自动改用后续空闲端口，并提示占用者是另一个
dashboard 还是别的程序。`--port 0` 让系统任意分配；`--strict-port` 恢复
「端口占用即报错退出」的行为。

页面会递归发现 `logs/**/*metrics_*.csv`、按修改时间列出，并自动加载最新文件；
刷新下拉框即可看到运行期间新生成的日志，不需要先下载再拖入。也可以直接双击
HTML 或手动选择/拖放任意 CSV 作为兜底。目录内提供 ECharts 5.5.0 浏览器构建，
图表不依赖 CDN 连通性；许可声明见 `ECHARTS_NOTICE.txt` 和仓库 `LICENSE`。

页面支持：

- 自动发现、下拉切换和刷新 `logs/` 内 CSV，也可点击或拖放加载；文件选择器
  优先显示收藏项，收藏可设置别名，侧栏始终显示当前 CSV 的完整路径；
- 按 `joint_position`、`joint_velocity`、`joint_torque`、`base` 等自动分类；
- 速度追踪按方向对比 `act_x/cmd_x`、`act_y/cmd_y`、`act_yaw/cmd_yaw`；
  其余按线速度误差（`err_x/err_y/err_xy_norm`）、角速度误差（`err_yaw`）、
  世界坐标位置、姿态角、站立标志分组。每组独立时间图、同单位分布与统计，
  不混用 m/s、rad/s、m、rad；缺失/未选/当前区间无数据的图组自动隐藏。
  未知字段按类型兜底保留；总览 PNG 和全部 PDF 使用相同分组；
- 世界坐标位置例外使用一张 XY 轨迹图（x 横轴、y 纵轴，均为 m），颜色表示
  时间，标注起点和终点并保持等比例；不再分开画 x/y 时间曲线，也不显示该组
  箱线图。轨迹按同时有效的 XY 样本绘制，缺失段不跨接；需同时勾选两坐标。
  时间区间筛选、总览 PNG 和 PDF 中的轨迹、时间色标保持一致；
- 隐藏位置、速度、扭矩等逐关节分类中不适用的 `total` 项，保留整机总机械功率
  及奖励等有意义的汇总。左右对比、T-N、惯量表按有效数据生成，不为缺失、
  当前时间区间全为缺失值或已取消选择的关节留空卡；左右对比导出也自动压紧布局。
  `0` 是有效数据，不会因为机器人静止而被隐藏；原始 CSV 不受影响；
- 同类型曲线叠加，以及「每个关节一行」的左右同名关节对比（行数随 CSV 里实际
  出现的关节数自适应，不写死关节名）；
- 独立的数据对比子界面：固定两份 CSV 后可连续添加多个对比项，每项独立展示；
  覆盖所有共同原始指标及派生加速度、惯量扭矩、机械功率和逐关节四象限 T-N；
- 独立的收藏总结子界面，可一键读取全部可用收藏文件，按指标展示跨文件
  RMS、P95、峰值图和完整统计表；
- 关节 T-N 四象限分析：按机械功率正负区分驱动/制动，支持绝对值折叠、
  电机曲线自动匹配、Q3 对称镜像和输出/吸收机械能汇总；
- 每个 T-N 关节图下显示合计及已勾选左右侧的驱动输出、制动吸收、零功率比例
  和有效样本数。占比按当前时间区间全部有效样本计算，不使用抽稀散点，
  也不把它解释为能量比例；工况筛选仅影响散点，不重置占比分母。
  逐关节比例同时保留在 T-N PNG 与 PDF 中；
- T-N 页的「保存左右对比 PNG」与「保存当前总览 PNG」均导出专用散点拼图，
  按当前勾选的左右关节、时间区间、驱动/制动筛选、rad/s 或 rpm、坐标轴顺序、
  四象限/绝对值模式生成，并保留电机曲线和额定虚线。
  「保存全部为 PDF」包含 T-N 与其余已选分类，图片解码完成后打开浏览器打印
  对话框，请选择「另存为 PDF」；生成过程有进度和错误提示；
- 侧栏常驻两张 DM 电机参考图；点击后可在视口内完整放大，支持滚轮缩放、
  放大后拖动图片、标题栏移动窗口、双击/按钮复位以及 Esc 关闭；
- 搜索、左右侧筛选、时间区间筛选、缩放和悬停读数；
- 侧栏“叠加左右脚步态”开关：浅蓝表示 CSV 左脚触地，浅红表示右脚触地，
  交叠表示双触地。默认关闭新增叠加，足端专用图原有接触提示保留；开启后去重
  原有接触色带，避免越叠越深。色带覆盖时序总览、左右对比、速度追踪、整机
  功率及足端多格时序图，随时间范围和图内缩放对齐，PNG/PDF 保留色带与说明。
  不叠到 T-N、XY/CoP 轨迹、压力空间图、箱线图或饼图上；
- 步态色带只认同一数据源的 `foot_contact/left`、`foot_contact/right` 有效 0/1
  标志，不按连续 phase、力值或缺失值猜测。缺哪一脚就不画哪一脚，记录最后
  一帧之后不外推持续时间，多环境混合日志需先拆分。对比页分别使用 A/B 自身
  触地数据，并严格跟随各自的相对时间或按样本序号归一化进度；A 实边、B 虚边。
  空白也可能是缺失数据，触地标志本身不代表承载力大小；
- 足端状态 → 接触几何与压力 → 压力场支持按时间滑条查看单帧左右脚压力、
  播放/暂停、上一帧/下一帧和 0.25×–2× 回放；色标在所选区间内固定。
  足底分布与时间回放统一使用俯视方向：前方 +x 向上、左方 +y 向左，
  按 x 方向 80 mm、y 方向 56 mm 的真实比例显示，窗口缩放/全屏时保持等比例；
  压力场左右面板顺序已交换为左侧右脚、右侧左脚，数据、脚侧标签及悬浮读数保持一致；
- 足端所有子页共用播放/暂停、逐帧、时间滑条与 0.25×–2× 速度，切换子页
  保留当前 CSV 帧。时序图显示同步深色游标；“当前帧原始读数”包含本组全部
  字段，不受侧栏勾选限制。区间统计、每步分布和压力聚合不伪装成瞬时值。
  接触力页增加左右脚法向/切向力的当前帧柱图，纵轴区间固定；切向力只表示
  记录的大小，不虚构方向，缺失不补零。压力图内控件与顶部时间条使用同一时钟。
- CoP 默认“当前帧回放”：与压力场一致的俯视方向、左右脚屏幕顺序和毫米等比例，
  圆点为当前 CoP，近期轨迹仅取当前连续有效段最近 1 s（非秒制最多 50 帧），
  不含未来、不跨腾空/缺失；有压力数据时叠加当前帧淡色压力底图，色标区间固定。
  仍可切换“区间轨迹”检查整段分布；PDF 保留区间轨迹，不修改实时播放状态。
  自动播放按真实时间戳推进；无秒制时间明确按 25 帧/秒回放，时间倒序/缺失或
  多环境混合时禁用自动播放，但允许手动逐帧检查。新 CSV 重置游标，区间裁剪夹紧游标。
- 足端各图使用独立标题、可换行图下注释和自适应单/双列，控制条与图形分开留白；
  全屏仍可操作同一播放时间条；CoP 区间轨迹在窄窗口下改为上下排列，XY 仍等比例，颜色表示时间，缺失段不跨接。
  CoP 灰框仅是 V031 名义采样网格（±40×±28 mm），不是实际接触凸包；
- 状态用区间条/阶梯，连续量用时序，落地姿态和支撑段峰值用事件点/柱，
  每步箱线按单位独立坐标轴（例如 N 与 N/s 不再共轴），悬浮显示样本步数。
  重复相同占空比的不同周期分别计数；区间首帧不伪造落地事件，冲击及累计滑移
  只统计有落地和离地证据的完整支撑段。缺列/全缺失图和无有效步的分布自动隐藏，
  未登记足端字段仅保留原始统计，不猜测单位；
- 足端不再假定旧机器人整机质量。可手填**整机**质量（不是 `base_link` 质量）
  显示 `mg`，未填仅显示“区间总法向力均值（非 mg）”；恒定 μ 不用来推断 DR 开关。
  足端专用图按可用字段自动组合，侧栏勾选用于 CSV 导出，全局区间作用于所有图。
  PDF 复用专用图及图注，压力导出区间聚合场，不生成混合量纲总览；
- 关节扭矩总览、左右对比和 T-N 图包含正负额定扭矩虚线：默认踝 DM3507
  为 ±0.8 N·m，其余 DM4310 为 ±3.5 N·m；导出 PNG/PDF 保留参考线。
  T-N 绝对值模式仅显示正额定值，交换坐标轴时参考线同步交换。
  额定值不等于峰值/仿真限幅；手选 T-N 曲线不改变真实关节的额定值；
- Min、Max、Mean、RMS、绝对峰值和绝对值 P95 统计；
- 导出当前分类总览 PNG、左右对比 PNG，以及当前区间的所选字段 CSV。

### 逐关节电机选型配置

点击顶部“电机选型配置”，在可折叠表格中为 CSV 实际存在的每个左右关节选择
DM4310 / DM3507 与**额外减速比**。左右可独立选择，也可一键复制到对侧。
手动配置优先于 XML 型号、再优先于默认映射；每行“恢复自动”回到 XML/默认值。
“清除手动配置”保留 XML；顶部“重置电机映射”同时清除 XML 和手动配置。

减速比 `i` 的口径已明确为“现有 T-N 曲线测量轴 → 关节输出轴”，不是包含电机
内置减速器的总比。默认 `i=1`；例如 DM3507 加额外 3:1 减速，填 `3`：

- 关节额定参考 = `0.8 × 3 = 2.4 N·m`；DM4310 的基准额定为 `3.5 N·m`；
- T-N 曲线逐点按 `τ_out=τ_ref×i`、`ω_out=ω_ref/i` 理想换算；同型号不同减速比
  分别画线，左右相同配置合并参考线，录制的关节运行点不变；
- 正负额定线、rpm/rad/s、轴互换、绝对值/Q3 镜像、跨文件 T-N 对比，以及
  总览/左右对比 PNG、全部 PDF 同步采用当前配置。PDF 附配置表；
- 电气估计的 Kt 须对应曲线参考输出轴，电流按 `|τ_joint|/(i×Kt_ref)` 计算。
  惯量需求仍使用手填 `J_total`，逐侧比较峰值与候选额定参考；瞬时超过额定
  不等于超过峰值能力。旧固定速度/力矩回退值另行标注，不与候选额定混淆。

配置保存在当前浏览器并跨 CSV 保留，可导出/导入带版本及减速比口径的 JSON。
无效型号、非有限或超出 0.001–1000 的比值会被拒绝，导入失败不改变当前配置。
这只是离线选型参考：不修改 XML、训练参数、原始 CSV、日志占用率或机械功率；
不自动推演更换电机后的质量、转子反射惯量与训练效果。传动损耗、齿轮承载、
热约束和制动回充能力未建模。静态数据手册图片保持原样；有限区间的 24 V
实测曲线不是完整能力包络，不能仅凭运行点离曲线的距离做选型结论。

Viser 录制的标准 CSV 至少包含：

```text
sample,sim_step,time_s,env_idx,network,<metric columns...>
```

### Viser 普通 / 静默录制

Metrics 页顶部的“录制控制”同时提供普通录制和静默录制，均保存当前任务注册的
**全部指标**，不删减足端 110 项。下方按腿部、手臂、足端、指令与机身等语义
分组的勾选仅控制实时曲线，不再决定录制列。未知指标仍保留在“其他”组。

- “实验前缀”默认 `experiment`，产物如
  `<当前模型日志目录>/experiment/experiment_metrics_<task-model>_<timestamp>_with_target.csv`、
  同目录同名 `.mp4` 和 `.recording.json`。每个实验名单独建目录，前缀支持中文，
  路径符号会清理，已有文件不会覆盖；现有旧文件不搬迁，网页递归发现新旧目录。
- “录制配置”可设置仿真时长（默认 10 s）、速度指令名称（默认 `twist`）、
  `current` 沿用任务指令 / `fixed` 固定 vx、vy、yaw / `random` 按各分量上下限
  均匀采样，以及随机指令切换间隔、专用随机种子。vx/vy 为 m/s，yaw 为 rad/s。
  固定/随机模式只支持 UniformVelocityCommand 及其子类；其他任务使用 current。
  这只控制录制环境的命令，不修改训练 ranges，不保证随机物理事件完全复现。
- 可选同步 1280×720 视频（默认开启），支持前/侧/斜视角与 10/25/50 FPS。
  视频实际 FPS 对齐控制步整数间隔，可能低于所选值，实际值写入 manifest。
  视频帧与 CSV 来自**同一个 rollout**，manifest 记录 CSV 样本、sim_step、
  仿真时间和视频帧时间。没有启动第二套策略；网页会自动关联同名视频和 manifest。
- 静默模式不按墙钟实时限速，不推送场景、相机、曲线和调试叠加，并隐藏场景，
  Metrics 页保留进度、状态和“取消并保存”。录制仍按每个仿真控制步采集全部数据，
  不随浏览器刷新率降采样。后台离屏视频渲染/编码仍有开销，追求速度可关闭视频。
- 时长单位是仿真秒，不是等待的实际秒数；终止、取消、失败或切换环境会提前结束。
  若环境自动 reset，最后那一步的旧 episode 指标不与新站姿画面配对，停止在
  最后一帧可对齐的数据。已录部分正常保存，manifest 标明结束原因和实际样本数。
  结束后恢复原来的暂停/运行状态与命令控制；失败时保持暂停。静默期间不接受
  新的 CSV 加载，结束后清空旧实时曲线历史，避免把中断前后误连成连续时间段。

无桌面的服务器录视频通常需以 `MUJOCO_GL=egl` 启动 play/Viser，且系统需可用
的 EGL 与 FFmpeg。更新 Python 后需重启 Viser/play 进程才生效；本功能不自动
终止或重启已有仿真。dashboard 服务需重启以启用带实验前缀 CSV 的自动发现。

### 视频与曲线同步播放

通过网页文件选择器加载服务器 CSV 后，自动关联
同名 MP4 与 `.recording.json`，按记录的 CSV 样本—视频帧映射对齐。统一时间轴
和所有足端图共用**底部唯一的常驻时间轴**，提供当前位置、播放/暂停、逐帧和
0.25× / 0.5× / 1× / 1.5× / 2× / 4× 倍速。放大图仍用同一条时间轴，不克隆控件；
时间曲线显示当前位置游标，XY 轨迹、分布图和 T-N 图不叠加时间游标。
底部“显示视频”打开悬浮画面，位置避开时间条；“分析区间”用起止值筛选图表、统计和导出，
不另放进度滑块。图表仍支持画布内缩放，但不再额外展示缩放滑条。
单击视频画面或聚焦后按空格/Enter，播放或暂停同一套数据时钟。小窗“循环”与
“视频同步设置”的“循环当前分析区间”同步：到区间尾部时，曲线、足端与录像一起返回
区间起点；不是独立设置 MP4 loop，倍速和分析区间均保留。默认不循环。

### 足底 3D 与摩擦统计

- **足底姿态 → 3D 法向重建**：随底部时间轴逐帧更新，可拖动旋转、滚轮缩放、
  双击复位。日志的 pitch/roll 是法向分量角，不是 Euler 旋转角；严格按
  `n = (sin(pitch), -sin(roll), cos(tilt))` 重建并检查一致性。
  目前没有 yaw/足部世界位置，故只能展示法向与参考平面：橙/绿轴是固定参考航向，
  不代表真实脚掌航向；两脚独立原点，80×56 mm 为名义采样范围，不是 XML 实体脚掌。
  缺失或不一致帧不画姿态，不推测高度、yaw 或穿透。
- **接触力与冲击 → 切向摩擦载荷**：每点为同一帧配对的 `(Fn, |Ft|)`，灰色边界
  使用区间 μ 最小/最大值作参考，不将不同帧的峰值组合成“合力”。没有 Ft_x/Ft_y，
  因此仅显示大小，不能判断摩擦方向。散点显示可抽样，统计使用全部有效帧。
- **CoP 与摩擦 → 摩擦锥 3D**：理想各向同性参考锥，单位法向截面的半径为 1；
  逐帧计算 `η=|Ft|/(μ Fn)`，绿/橙/红环为 P50/P95/最大 η，圆环明确表示方位未知，
  不是实测力箭头或方向概率。附有效帧数、Fn/|Ft| P95、μ 范围与触界帧占比。
  有 contact 列时只纳入严格 contact=1；否则仅按 Fn>0.001 N 筛选承载帧。
  无效力/μ、腾空不参与归一化分母；触界 η≥1−1e−6（数值容差）不等于已打滑，
  帧占比也不是时间占比。μ 来自日志足部 geom 平均值，不是逐接触有效摩擦系数。

上述 3D 视图不需要 WebGL 或新增在线库，仍支持图表放大、分析区间筛选与 PDF 导出。
姿态 PDF 为当前帧快照，摩擦锥为选定区间统计；不修改原始 CSV，也不反推缺失分量。

顶部“导入 CSV”选择本地文件，也支持把 CSV 拖到该按钮，不占用大块拖放区域。
“实时源设置”“视频同步设置”按需展开；后者可选择本地视频和时间映射文件。
没有 manifest 时只按相对秒数
近似对齐并明确提示，可配置视频时间偏移；不把无映射的视频当作精确同步录像。
仅秒制横轴可自动同步视频。文件名、网络名和完整路径可换行显示。

### 同步实时仿真

1. 重启使用新代码的 Viser/play，在 Metrics 顶部勾选“同步实时数据到 dashboard”。
2. 网页展开“实时源设置”，点击“刷新源”，选择对应模型/环境并连接；默认最近 **10 s** 窗口，
   可配置 **1–300 s**，刷新率可选 1/2/5 Hz。图表与足端快照自动跟随最新样本。
3. 底部时间轴在实时模式显示“实时跟随”，不可拖动或改变仿真速度；点击“暂停接收”
   保留当前窗口后，可使用同一时间轴回放及导出。加载历史 CSV 也会断开实时源。

实时发布默认关闭，开启后按控制步采集全部已注册指标。生产端只有最多 15,000 条
内存环形缓冲，不逐步写文件、不重新运行策略；高控制频率下可保留时长受条数上限约束。
切换模型、环境或 reset 会清空旧时间段，避免串接不同轨迹。暂停仿真时显示等待新数据。
实时曲线不自动关联历史视频；它与 CSV/720p 录制是独立开关，仍可同时录制用于事后分析。
传输只绑定服务器 loopback，并由 dashboard 只读代理；浏览器无需额外映射 Viser 数据端口。

网页也接受额外 Metrics，并会按列名前缀动态分类。

**横轴不必是 `time_s`。** 页面按 `time_s → time → sim_step → step → iteration →
iter → epoch → frame → sample` 的顺序取第一个**数值且单调不减**的列当横轴，
都找不到时退化为样本序号（此时横轴标注为「样本序号」）。所以训练趋势 CSV
（例如 `docs/pikachu_v03/reports/r06b-train-trend.csv`，只有 `iter,sep_cm,…`）
可以直接导入，横轴就是 `Iteration`，其余列全部可绘；被选作横轴的列不会重复出现在
曲线列表里。只有「一个数值列都没有」才会报错。

**关节名不写死。** 任何 `left_/right_<关节>_joint` 形式的列都会被自动发现，
按 `hip_pitch → hip_roll → hip_yaw → knee → ankle → arm_pitch → arm_roll` 的顺序
排列，不在其中的按名字排在后面。所以 pikachu_v03 的膝叫 `knee_up`（而不是
`knee`）时，它照样出现在左右对比、T-N 四象限和惯量面板里。若新机型的某个关节
还需要借用已知关节的电机规格/惯量默认值，在页面脚本的 `JOINT_ALIASES` 里加一条
别名即可（现有：`knee_up → knee`，于是 knee_up 自动用 J4310 规格）。

**电机 XML 适配。** 点击「导入电机 XML」，自动读取 MJCF 执行器 `joint`
对应 `name`/`class` 中的 3507/4310 型号（支持嵌套 default 类继承），或明确配置：

```xml
<custom>
  <text name="motor/left_ankle_joint" data="DM-J3507"/>
  <text name="motor/right_ankle_joint" data="DM-J3507"/>
</custom>
```

映射同时应用于额定虚线、T-N 自动曲线、电气功率估算；支持左右侧分别配置。
未匹配的关节保留「ankle=3507，其余=4310」默认值；可点击「重置电机映射」。
导入映射仅在当前页面会话有效，切换 CSV 时保留，分析另一机器人前应重置/重新导入。
浏览器不会自动读取 XML 的 include 文件，请提供展开的 XML。仅含结构/惯性的原始
训练 XML（执行器由 Python 创建）无法推断电机型号，页面会提示并保持现有映射，
不会从 `forcerange`/`ctrlrange` 猜测额定扭矩，也不会改动训练参数。

## Response CSV Dashboard

`response_csv_dashboard.html` 用于分析 `uv run response <TASK>` 导出的
`response.csv`。它与 `mjlab-response-v1` 长表 schema 对齐，提供：

- 按关节、step/sine 和 case 筛选的位置、误差、速度、扭矩同步波形；
- 上升时间、延迟、超调、调节时间、稳态误差、IAE/ISE 和饱和占比；
- 每个频点未经拟合的原始正弦 command/measured 时域曲线；
- 正弦基波最小二乘拟合、Bode 增益/相位、等效延迟、THD 和 −3 dB 带宽；
- 扭矩–转速散点、峰值/RMS 扭矩、机械功率和可调安全系数选型建议；
- 当前电机型号、限位、PD、关节惯量、armature、减速器与占位/未知参数状态；
- MathJax/LaTeX 渲染的模型推导和当前关节数值代入；
- NaN/缺失值分类诊断，区分未知电机参数、未达到判据和频率覆盖不足。

在同一服务下打开
`http://localhost:8000/scripts/plot_logs/response_csv_dashboard.html`。页面会发现
`logs/response/**/response.csv` 并自动加载最新一次运行。
